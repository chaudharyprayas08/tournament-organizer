📊 Ranking Rules

Legend: P=Played · W=Wins · L=Losses · PF=Points For · PA=Points Against

Sort order:
  1. Points — Win=2, Loss=0
  2. NRR = (PF−PA)/P — avg margin per match
  3. PR = PF/PA — points scored ÷ conceded (∞ if PA=0)
  4. PF — total points scored
